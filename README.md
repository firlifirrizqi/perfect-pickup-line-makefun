# The Perfect Pickup Line

One short pickup line an AI agent could say out loud, written for the
[Make.fun bounty](https://make.fun/bounty/u-pucuys-the-perfect-pickup-line-f6725cf6).
It turns on a double meaning: a context window is the agent's own memory — and
"more of you in it" is also the oldest come-on there is.

`main.py` writes the line to `/output/entry.txt`:

> I don't need a bigger context window — I just need more of you in it.

Run it with `python3 main.py`.
